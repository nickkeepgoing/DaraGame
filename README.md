# 🦕 DaraGame

เกมวิ่งหนีลาวาวันสิ้นโลก ธีมไดโนเสาร์ T-Rex — 2D side-scroller พร้อมระบบคำถามและกระดานคะแนนสำหรับห้องเรียน
**ออกแบบให้เล่นบนมือถือแนวนอนเป็นหลัก** (iOS + Android) เล่นบนคอมก็ได้

> ไดโนเสาร์สูญพันธุ์เพราะอุกกาบาตชนโลกเมื่อ 66 ล้านปีก่อน — "กำแพงวันสิ้นโลก" ที่ไล่ผู้เล่นในเกมนี้จึงเป็นคลื่นลาวาจากการชนครั้งนั้นจริงๆ

## 🎮 โครงเกม

```
ด่าน 1 · รู้จักการชนกัน   →  3 คำถาม (ง่าย)
ด่าน 2 · เขตมุดตัว        →  3 คำถาม (ปานกลาง)
ด่าน 3 · ผลจากการชนกัน    →  3 คำถาม (ยาก)
👑 บอสสุดท้าย            →  ตอบถูก = ชนะเกม
💀 ตายระหว่างทาง          →  ตอบคำถามฟื้นถูก = กลับไปที่จุดตรวจล่าสุด (ฟื้นได้ 2 ครั้ง)
```

**หมวดเนื้อหาปัจจุบัน:** การชนกันของแผ่นเปลือกโลก (Convergent Plate Boundary) — **46 คำถาม**
(ด่านละ 12 ข้อ × 3 ด่าน + คำถามฟื้น 6 + บอส 4) — รอบหนึ่งใช้แค่ 3 ข้อต่อด่าน **จึงไม่มีทางเจอซ้ำในรอบเดียว**
และสุ่มใหม่ทุกรอบ เล่นซ้ำหลายรอบก็ยังเจอคำถามใหม่

**ของในด่าน:** 📦 กล่องปริศนากระโดดชนจากข้างล่างแบบมาริโอ — ได้หัวใจถ้ายังไม่เต็ม ไม่งั้นได้โบนัสระยะทาง

## เริ่มเล่นใน 30 วินาที

```bash
npm install && npm run dev
```

เปิด http://localhost:5173 — **เล่นได้เลย ไม่ต้องตั้งฐานข้อมูลก่อน**
ถ้ายังไม่ได้ตั้งค่า Supabase เกมจะรันใน **โหมดออฟไลน์** อัตโนมัติ (คำถามจากไฟล์ในเครื่อง, คะแนนเก็บใน localStorage)

**เล่นบนมือถือ:** เทอร์มินัลจะแสดง `Network: http://192.168.x.x:5173/` เปิด URL นั้นบนมือถือในวง WiFi เดียวกัน

| ปุ่ม | ทำอะไร |
|---|---|
| `← →` / `A D` / ปุ่ม **◀ ▶** บนจอ | เดิน — กดขวาค้างเพื่อเร่ง (จำเป็นถ้าอยากหนีกำแพงทัน) |
| `↑` / `W` / `Space` / ปุ่ม **▲** บนจอ | กระโดด — กดค้างยิ่งนานยิ่งสูง |
| `↓` / `S` / ปุ่ม **▼** บนจอ | หมอบ |
| กระโดดชนกล่อง 📦 จากข้างล่าง | เปิดกล่อง — ได้หัวใจ หรือโบนัสระยะทาง |
| `1` `2` `3` `4` | ตอบคำถาม |
| `` ` `` | เปิดแผงจูนค่าแบบสด (เฉพาะตอน dev) |

ปุ่มบนจอจะขึ้นอัตโนมัติบนอุปกรณ์ที่มีทัชสกรีน — บนคอมเปิดดูได้ด้วย `?buttons=1`

## 🛠 Tech Stack

```
Phaser 3.90 (เกมเพลย์)  +  React 18 (UI ภาษาไทย)  +  TypeScript  +  Vite  +  Tailwind 4
                     ↓
        Supabase (PostgreSQL + Auth + RLS + RPC)
                     ↓
                  Vercel
```

**ยังไม่มีไฟล์ asset สักไฟล์** — กราฟิกวาดด้วย Phaser Graphics ตอนรัน ([`textures.ts`](src/game/systems/textures.ts))
และเสียงสังเคราะห์สดด้วย Web Audio ([`sfx.ts`](src/audio/sfx.ts))
พอถึงสัปดาห์ที่ 6 ให้เปลี่ยนเป็น texture atlas จริงโดยใช้ชื่อ key เดิม — ส่วนอื่นไม่ต้องแก้

## ⚠️ กฎที่ห้ามลืม

1. **ทุกการเคลื่อนที่ต้องคูณ `delta`** ไม่งั้นคนจอ 144Hz วิ่งเร็วกว่าเพื่อน 2.4 เท่า → leaderboard เป็นโมฆะ
2. **คะแนนคำนวณที่เซิร์ฟเวอร์เสมอ** client ส่งได้แค่ข้อมูลดิบ (ตอบข้อไหน / วิ่งกี่เมตร)
3. **`service_role` key ห้ามอยู่ใน `src/` เด็ดขาด** — Vite จะ bundle ตัวแปร `VITE_*` เข้าไฟล์สาธารณะ
4. **ข้อความไทยอยู่ใน DOM เท่านั้น** ห้ามใช้ Phaser `BitmapText` กับภาษาไทย (สระ/วรรณยุกต์จะหลุด)
5. **ตัวเลขปรับสมดุลอยู่ใน [`src/config/balance.ts`](src/config/balance.ts)** ไฟล์เดียว — และค่าคะแนนต้องตรงกับ [`db/03_rpc.sql`](db/03_rpc.sql)
6. **`unlock()` ต้องถูกเรียกจาก user gesture** ไม่งั้น iPhone จะเงียบสนิท
7. **คำถามทุกข้อต้องมี `role` และ (ถ้าเป็น main) `stage`** ไม่งั้นเกมจะหาคำถามของด่านนั้นไม่เจอ
