# 04 — Roadmap & MVP Scope

---

## 1. MVP — เส้นแบ่งที่ห้ามข้าม

**นิยาม MVP:** *นักเรียนเปิดลิงก์ พิมพ์ชื่อเล่น เล่นจนตาย เห็นคะแนนตัวเองบนกระดานเทียบกับเพื่อน*

ถ้ายังทำสิ่งนี้ครบวงจรไม่ได้ **ห้ามเริ่มทำอย่างอื่นทั้งสิ้น**

### ✅ อยู่ใน MVP — **ทำเสร็จแล้ว**

- [x] Login: ชื่อเล่น + รหัสห้อง (anonymous auth) + จำผู้เล่นเดิมไว้
- [x] หน้าวิธีเล่น + นับถอยหลัง
- [x] วิ่ง / กระโดด / หมอบ — มี coyote time + jump buffer + variable jump height
- [x] กำแพงลาวาไล่ + เร่งความเร็วตามเวลา + ตายเมื่อโดนทับ
- [x] หัวใจ 3 ดวง + i-frame หลังโดนชน
- [x] ตัวขวาง: ก้อนหิน / ต้นเฟิร์น / ไข่ไดโน / อุกกาบาตตกจากฟ้า / หลุมลาวา
- [x] Checkpoint คำถาม → popup → ตรวจที่เซิร์ฟเวอร์ → โชว์เฉลย+คำอธิบาย
- [x] HUD: หัวใจ / คะแนน / ระยะทาง / มาตรวัดระยะห่างกำแพง
- [x] Game Over + สรุปคะแนน + **รายการข้อที่ตอบผิดพร้อมคำอธิบาย**
- [x] Leaderboard (รวม + แยกห้อง)
- [x] เล่นได้บนมือถือแนวนอน (iOS + Android) พร้อมปุ่มควบคุมบนจอ — ดู [07-mobile.md](07-mobile.md)
- [x] **โครงด่าน 1-3 + บอสสุดท้าย + ชนะเกมได้** (เพิ่มทีหลังตามชุดคำถามที่ได้มา)
- [x] **คำถามฟื้นตอนตาย** — ตอบถูกกลับไปจุดตรวจล่าสุด ฟื้นได้ 2 ครั้ง
- [x] หน้า "หมุนจอเป็นแนวนอน" คั่นก่อนเข้าเกม
- [x] เสียง SFX ครบ + เพลงพื้นหลังที่เข้มขึ้นเมื่อกำแพงใกล้
- [x] ฉากเปลี่ยนตามระยะทาง 3 ช่วง (biome) + parallax 3 ชั้น
- [x] สร้างด่านจาก seed — ครูตั้ง seed ให้ทั้งห้องเจอด่านเดียวกันได้
- [x] Anti-cheat 4 ชั้น + ระบบ flag ให้ครูตรวจ
- [x] **โหมดออฟไลน์** — เล่นได้ทันทีโดยไม่ต้องตั้ง Supabase (ทำก่อนกำหนด)
- [x] **แผงจูนค่าแบบสด** กด ` (ทำก่อนกำหนด — จำเป็นสำหรับ playtest)
- [x] คำถามครบตามโครงที่ออกแบบ (9 ประจำด่าน + 2 ฟื้น + 1 บอส = 12 ข้อ)
- [ ] **Playtest กับนักเรียนจริง แล้วจูนตัวเลขจากข้อมูลจริง** 🔴

### ⏸ ยังไม่ทำ (ลิสต์ "ถ้ามีเวลาเหลือ")

ปลดล็อกตัวละคร · โหมดท้าเพื่อน/แชร์ลิงก์ · หน้า dashboard ครู · leaderboard รายสัปดาห์ · หลุมดำดูดผู้เล่น · เพื่อนไดโนวิ่งสวน · power-up หัวใจ · PIN 4 หลัก · Service Worker (เล่นได้ตอนเน็ตหลุด) · haptic feedback · sprite/atlas จริงแทนกราฟิกที่วาดด้วยโค้ด

### 🔴 สิ่งที่เหลือคือ "คอขวดจริง" ของโปรเจกต์นี้

โค้ดครบแล้ว เนื้อหาครบตามโครงแล้ว — สิ่งที่ยังกั้นอยู่คือ **การจูนจากผู้เล่นจริง**

**สิ่งที่ยังยืนยันไม่ได้จนกว่าจะมีคนเล่นจริง:**
- เด็กมัธยมเล่นจนถึงบอสได้กี่ % — ตอนนี้รู้แค่ว่า "บอตที่กดเร่งค้างและไม่โดนอะไรเลย" ไปถึงได้
- ปุ่มบนจอวางถูกที่สำหรับนิ้วโป้งจริงหรือยัง
- กำแพงกดดันพอไหม (บอตที่กดเร่งตลอดไม่เคยโดนไล่ทันเลย ระยะห่างค้างที่เพดาน 1500 px)
- 12 ข้อพอสำหรับเล่นซ้ำไหม หรือจำคำตอบได้ตั้งแต่รอบที่ 2

ทั้งหมดนี้จูนได้ด้วยแผงสไลเดอร์ (กด `` ` ``) โดยไม่ต้อง build ใหม่

> ทุกอย่างในลิสต์นี้ทำได้จริงและเจ๋งทั้งนั้น — แต่**ทีมที่ทำของพวกนี้ก่อนกำแพงจะไล่ได้ คือทีมที่ส่งงานไม่ทัน**

## 2. แผน 8 สัปดาห์

| สัปดาห์ | เป้าหมาย | ส่งมอบอะไร (ต้องเห็นด้วยตา) |
|---|---|---|
| **1** | ตั้งโปรเจกต์ + วิ่งกระโดดได้ | Vite+Phaser รันได้ · **สี่เหลี่ยมสีวิ่งกระโดดบนพื้นได้ ลื่นแล้ว** · repo + CI deploy ขึ้น Vercel · เริ่มเขียนคำถามหมวดแรก |
| **2** | Core loop ครบ (ยังไม่มี backend) | กำแพงไล่ + ตาย · ตัวขวาง 3 แบบ + หัวใจ · Debug panel · **เล่นแล้วสนุกได้แล้วแม้ยังเป็นสี่เหลี่ยม** |
| **3** | Backend + ควิซ | สคีมา+RLS+RPC ขึ้น Supabase · login ได้ · checkpoint เปิด popup ถามได้ · import คำถามจาก CSV ได้ |
| **4** | ครบวงจร | `finish_run` บันทึกคะแนน · Leaderboard ใช้ได้จริง · **🔴 PLAYTEST กับเด็กจริง 5 คน** |
| **5** | จูน + มือถือ | ปรับสมดุลจากผลเทส (ควิซต้อง ≥55% ของคะแนน) · touch control · หน้าจอมือถือ |
| **6** | อาร์ต + เสียง | เปลี่ยนสี่เหลี่ยมเป็นไดโนจริง · parallax · เอฟเฟกต์กำแพง · SFX+BGM ครบ |
| **7** | ขัดเงา + เนื้อหา | ขยายคลังคำถาม (เพิ่มด่าน/ชุดที่ 2) · หน้า UI ทุกหน้าสวย · แก้บั๊กจาก playtest รอบ 2 · CREDITS.md |
| **8** | ส่ง | ทดสอบข้ามเครื่อง/เบราว์เซอร์ · เช็กลิสต์ความปลอดภัย · เอกสาร · **ซ้อมนำเสนอบนเน็ตโรงเรียนจริง** + อัดวิดีโอสำรอง |

> **บีบเหลือ 4-5 สัปดาห์ได้ไหม?** ได้ — รวมสัปดาห์ 1-2 เข้าด้วยกัน, อยู่ที่ 12 คำถามไม่ต้องขยาย, ใช้ Kenney assets ล้วนไม่วาดเอง แต่**ห้ามตัดสัปดาห์ที่ 4 (playtest)** ทิ้ง เกมที่ไม่เคยให้คนอื่นเล่นคือเกมที่ยากเกินไปเสมอ

## 3. หลักการเรียงงาน (ทำไมถึงเรียงแบบนี้)

```
สัปดาห์ 1-2 : ทำให้ "สนุก"  ← ถ้าสี่เหลี่ยมสีวิ่งแล้วยังไม่สนุก ใส่ไดโนน่ารักก็ไม่ช่วย
สัปดาห์ 3-4 : ทำให้ "ครบ"   ← ต่อ backend ให้ครบวงจรเร็วที่สุด จะได้รู้ว่าพังตรงไหน
สัปดาห์ 5-6 : ทำให้ "สวย"   ← อาร์ตมาทีหลัง เพราะถ้าเกมเพลย์เปลี่ยน อาร์ตต้องวาดใหม่
สัปดาห์ 7-8 : ทำให้ "เสร็จ" ← เผื่อเวลาไว้ 2 สัปดาห์เสมอ มันจะหมดไปกับบั๊กที่ไม่คาดคิด
```

**ห้ามทำอาร์ตก่อนเกมเพลย์นิ่ง** — ถ้าจูนแล้วพบว่าตัวละครต้องกระโดดสูงขึ้น sprite ทั้งชุดอาจต้องปรับสัดส่วนใหม่หมด

## 4. แบ่งงาน (ทีม 3-4 คน)

| บทบาท | รับผิดชอบ | สัปดาห์ที่ยุ่งสุด |
|---|---|---|
| **Gameplay** | Phaser scenes, physics, กำแพง, ตัวขวาง, LevelGen, Debug panel | 1-2, 5 |
| **Frontend/UI** | React screens, QuizModal, HUD, Leaderboard, มือถือ | 3-4, 6 |
| **Backend/Data** | สคีมา, RLS, RPC, import script, anti-cheat, deploy | 3-4 |
| **Content/Art** | คำถาม + คำอธิบายทุกข้อ, sprite, เสียง, CREDITS | **ตลอดทั้ง 8 สัปดาห์** |

> ถ้าทีมมี 2 คน: คนหนึ่งเอา Gameplay+Art อีกคนเอา Frontend+Backend
> ถ้าทีมมีคนเดียว: ใช้ Kenney assets ล้วน และอยู่ที่ 3 ด่านตามที่ทำไว้

## 5. Definition of Done (เช็กก่อนบอกว่าเสร็จ)

**เกมเพลย์**
- [ ] วิ่ง 60 วินาทีบน CPU throttle 4x ได้ระยะทางใกล้เคียงกับตอนไม่ throttle (delta ถูกต้อง)
- [ ] เล่น 5 รอบติดไม่มี memory leak (DevTools → Memory ไม่ไต่ขึ้นเรื่อยๆ)
- [ ] กด "เล่นใหม่" 3 รอบ คะแนนไม่บวกซ้ำ (EventBus cleanup ถูกต้อง)
- [ ] สลับแท็บไป 30 วินาทีแล้วกลับมา ตัวละครไม่ทะลุพื้น

**ความปลอดภัย**
- [ ] `curl .../rest/v1/choices?select=*` ต้องถูกปฏิเสธ
- [ ] `grep -rn "service_role" src/ .env*` ไม่เจออะไร
- [ ] Supabase Advisors → Security ไม่มี warning สีแดง
- [ ] แก้ตัวแปรคะแนนใน DevTools แล้วส่ง — คะแนนใน DB ต้องไม่เปลี่ยน

**สมดุล**
- [ ] `quiz_pct` จากตาราง `runs` ≥ 55%
- [ ] เด็กที่เล่นครั้งแรกอยู่รอด 45-90 วินาที (ไม่ตายใน 15 วิ ไม่เล่นยาว 5 นาที)
- [ ] เด็กอย่างน้อย 1 ใน 3 คนไปถึงบอสสุดท้ายได้ (ถ้าไม่ถึงเลย = กำแพงเร็วไป / ตัวขวางถี่ไป)

**ใช้งานจริง**
- [ ] เล่นบน iPhone Safari + Android Chrome ได้ **และมีเสียง**
- [ ] เล่นบน Chrome/Edge/Firefox บนคอมได้
- [ ] โหลดครั้งแรก ≤ 4 MB และมีหลอดโหลด
- [ ] `docs/CREDITS.md` ครบทุกไฟล์
